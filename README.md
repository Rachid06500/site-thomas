# Site Thomas - Graphiste freelance

## Présentation

Site vitrine réalisé dans le cadre de ma formation Product Builder No Code & IA. Il présente l'activité de Thomas, graphiste freelance, ses compétences, ses réalisations et un formulaire de contact.

## Technologies utilisées

- HTML5 : structure et contenu de la page.
- CSS3 : mise en forme et adaptation aux différentes tailles d'écran.

## Fonctionnalités

- Menu de navigation avec liens vers les sections.
- Présentation de Thomas avec portrait.
- Section compétences.
- Section réalisations.
- Formulaire de contact.
- Affichage responsive sur ordinateur et mobile.
- Favicon personnalisé.

## Structure du projet

- `index.html` : page principale du site.
- `styles/style.css` : feuille de style CSS.
- `assets/Thomas.png` : portrait utilisé dans la page.
- `assets/favicon.png` : icône du site.

## Lancer le projet en local

1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir `index.html` avec l'extension Live Server.
3. Tester la navigation et l'affichage sur ordinateur et mobile.
